# Prompt Forge

## Project Description
Prompt Forge is a powerful tool designed to streamline the process of creating prompts for machine learning models. With an intuitive interface and adaptable templates, users can easily craft, modify, and manage prompts to enhance their interactions with AI technologies.

## Installation
To install Prompt Forge, clone the repository and run the installation command:

```bash
git clone https://github.com/matysekprogramuje/prompt-forge.git
cd prompt-forge
npm install
```

## Usage
After installation, start the application by using:

```bash
npm start
```

You can then access the application by navigating to `http://localhost:3000` in your web browser.

## Features
- **User-friendly Interface**: Designed for ease of use with minimal learning curve.
- **Customizable Templates**: Create and modify prompt templates according to your needs.
- **Real-time Preview**: See prompt results in real-time to refine your queries.
- **Export Options**: Export your prompts in various formats for easy sharing.

## Technology Stack
- **Frontend**: React for building user interfaces.
- **Backend**: Node.js and Express for server-side logic.
- **Database**: MongoDB for data storage.
